## 物理量
```
inline float rho0, ux0, uy0;
constexpr int Q = 9;
constexpr std::array<int, Q> cx = {0, 1, 0, -1, 0, 1, -1, -1,  1};
constexpr std::array<int, Q> cy = {0, 0, 1,  0,-1, 1,  1, -1, -1};
constexpr std::array<float, Q> w = {
    4.f/9.f, 
    1.f/9.f, 1.f/9.f, 1.f/9.f, 1.f/9.f,
    1.f/36.f, 1.f/36.f ,1.f/36.f, 1.f/36.f
};
constexpr int nx = 200;
constexpr int ny = 50;
inline std::array<float, nx * ny * Q> f;
inline std::array<float, nx * ny * Q> f_next;
inline std::array<float, nx * ny> rho;
inline std::array<float, nx * ny> ux;
inline std::array<float, nx * ny> uy;
constexpr float tau = 0.6f;
constexpr float Fx = 1e-6f;
```
* $rho0$, $ux0$, $uy0$: 初始状态，用于初始化
* $Q$: 9个方位
* $cx$, $cy$: 标准D2Q9，用于确定方位
* $w$: 权重
* $f$: x方向nx个格点，y方向ny个格点，分布函数：粒子向离散速度$c_k$方向的质量概率密度
* $rho$, $ux$, $uy$ 数组：各点的密度和速度分量
* $\tau$: 弛豫时间，决定了分布函数回到平衡态的快慢，对应N-S方程中的$\nu$运动粘度系数
* $Fx$: 泊肃叶流x轴方向的扰动力
* $Re$: 雷诺数，$Re=\frac{U D}{\nu}$
## 过程
1. 初始化 \
`void initialize()`
2. 计算宏观量 \
`void macro()`
3. 碰撞（BGK模型）\
`void collide()`
4. 传播 \
`void stream(const std::array<float, nx * ny * Q>& f_next)`
5. 边界条件 \
`void bounce_back()`
6. 迭代 \
`void simulate_D2Q9()`
## 公式
* D2Q9离散速度
$$\mathbf{c}_k = (c_{x,k}, c_{y,k}), \quad k = 0,\dots,8$$
* 权重$w_k$
$$
w_k = 
\begin{cases}
\frac{4}{9}, & k = 0 \\
\frac{1}{9}, & k = 1,2,3,4 \\
\frac{1}{36}, & k = 5,6,7,8
\end{cases}
$$
* 宏观量
    - 密度
    $$\rho = \sum_{k=0}^{8} f_k$$
    - 动量
    $$
    \rho u_x = \sum_{k=0}^{8} f_k c_{x,k} \\
    \rho u_y = \sum_{k=0}^{8} f_k c_{y,k}
    $$
* 平衡态分布函数$f_k^{eq}$
$$
f_k^{eq}
= w_k \rho \left[
1 + 3(\mathbf{c}_k \cdot \mathbf{u})
+ \frac{9}{2} (\mathbf{c}_k \cdot \mathbf{u})^2
- \frac{3}{2} |\mathbf{u}|^2
\right]
$$
```
int flat = i*nx + j;
int base = flat * Q;
float u2 = ux0*ux0 + uy0*uy0;
for (int k = 0; k < Q; ++k) {
    float cu = 3.f * (ux0*cx[k] + uy0*cy[k]);
    float feq = w[k] * rho0 * (1.f + cu + 0.5f*cu* cu - 1.5f*u2);
    f[base + k] = feq;
}
```
* BGK碰撞（$Fx$外力）
$$
f_k^{\text{post}}
= f_k
- \frac{1}{\tau}(f_k - f_k^{eq})
+ \left(1 - \frac{1}{2\tau}\right) F_k
$$
```
f_next[base + k] = f[base + k] - (f[base + k] - feq) / tau + (1.f - 0.5f/tau) * Fk;
```
* Guo外力项
$$
F_k
= w_k \left[
3(\mathbf{c}_k \cdot \mathbf{F})
+ 9(\mathbf{c}_k \cdot \mathbf{u})(\mathbf{c}_k \cdot \mathbf{F})
- 3(\mathbf{u} \cdot \mathbf{F})
\right]
$$
```
float term1 = 3.f * eF[k];
float term2 = 9.f * eu[k] * eF[k];
float term3 = -3.f * (ux_ij * Fx);
float Fk = w[k] * (term1 + term2 + 0.5f * term3);
```
* 传播
$$f_k(\mathbf{x} + \mathbf{c}_k, t+1) = f_k^{\text{post}}(\mathbf{x}, t)$$
```
int i_next = (i + cy[k] + ny) % ny;
int j_next = (j + cx[k] + nx) % nx;
f[index(j_next, i_next, k)] = f_next[index(j, i, k)];
```
* 弛豫时间$\tau$与运动粘度系数$\nu$
$$
\nu = c_s^2 \left(\tau - \frac{1}{2}\right)
$$
对于D2Q9，$c_x^2$ = $\frac{1}{3}$，即：$\nu = \frac{1}{3}\left(\tau - \frac{1}{2}\right)$
